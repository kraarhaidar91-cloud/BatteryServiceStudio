# Battery Service Studio

برنامج Windows مستقل بواجهة رسومية عربية لخدمة وتشخيص بطاريات اللابتوب عبر CP2112/SMBus.

## البناء
يفتح المشروع في Visual Studio 2022 أو يبنى بواسطة GitHub Actions.

## ملاحظة
عمليات Data Flash/EEPROM والكتابة الخاصة بالمتحكمات يجب تنفيذها حسب المتحكم والبروتوكول الموثق، ولا يتم تنفيذ كتابة عامة عشوائية على البطارية.

الإصدار الحالي يضع واجهة Windows حقيقية ويجهز مسار البناء والتثبيت، وسيتم توسيع طبقة CP2112 وقراءة SBS ثم دعم المتحكمات تدريجياً.
