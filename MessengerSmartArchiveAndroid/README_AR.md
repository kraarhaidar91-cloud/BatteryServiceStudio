# أرشيف ماسنجر الذكي — Android

تطبيق أندرويد بواجهة عربية لاستيراد نسخة محادثات Facebook/Messenger والبحث داخلها.

## مهم قبل الاستخدام
هذا التطبيق لا يستطيع تسجيل الدخول إلى حساب Messenger أو سحب الرسائل مباشرة. استخدم ميزة **تنزيل معلوماتك** الرسمية في مركز حسابات Meta، ثم استورد ملف ZIP الذي تحصل عليه. لا تعطِ كلمة مرورك لأي تطبيق آخر.

1. افتح https://accountscenter.facebook.com/info_and_permissions/
2. افتح **معلوماتك وأذوناتك** ثم **تنزيل معلوماتك**.
3. اختر حساب Facebook وحدد الرسائل ضمن أنواع المعلومات.
4. اختر JSON، وحدد الفترة الزمنية المطلوبة، ثم أنشئ ملف التنزيل.
5. بعد جاهزية الملف نزّله على الهاتف، وافتح هذا التطبيق واختر **استيراد نسخة المحادثات (ZIP أو JSON)**. يمكن اختيار ملف ZIP مباشرة دون فك ضغطه، أو اختيار ملف \`message_1.json\` من مجلد الرسائل.

## الميزات الحالية
- استيراد ملفات ZIP الصادرة عن Facebook أو ملف محادثة JSON منفرد.
- البحث في نصوص الرسائل حسب الكلمات والأسماء.
- استخراج أرقام الهاتف والبريد الإلكتروني والعناوين المحتملة من نصوص الرسائل.
- عرض تفاصيل النتيجة ومصدرها.

## الحدود
- لا يوجد اتصال مباشر أو تسجيل دخول إلى Messenger.
- دقة اكتشاف العناوين احتمالية؛ راجع نص الرسالة الأصلي.
- في النسخة الحالية، نتائج البحث محفوظة في الذاكرة أثناء جلسة التطبيق، ولا تُحفظ بعد إغلاق التطبيق.
- بعض الرسائل أو المحادثات المشفّرة قد لا تكون في التصدير المتاح؛ يعتمد ذلك على البيانات التي يتيحها فيسبوك لحسابك.
