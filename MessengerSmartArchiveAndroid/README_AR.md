# أرشيف ماسنجر الذكي — Android

تطبيق أندرويد بواجهة عربية لاستيراد ملفات JSON من نسخة بيانات Messenger/Facebook والبحث في الرسائل واستخراج أرقام الهاتف والبريد الإلكتروني والعناوين المحتملة.

## الحصول على ملف APK
يُبنى التطبيق تلقائيًا عبر GitHub Actions عند تحديث ملفات هذا المجلد. افتح تبويب **Actions** في المستودع، ثم افتح أحدث تشغيل باسم **Build Messenger Android APK** ونزّل الأثر (Artifact) باسم **MessengerSmartArchive-debug-apk**. يحتوي ZIP الناتج على ملف APK تجريبي موقّع بمفتاح debug ويمكن تثبيته على هاتف أندرويد.

## حدود النسخة
- يستورد ملف JSON واحدًا في كل مرة؛ عادةً ملف `message_1.json` داخل تنزيل بيانات Facebook.
- البحث والنتائج الحالية محفوظة في الذاكرة أثناء تشغيل التطبيق فقط.
- كشف العناوين تقريبي ويجب التحقق من النص الأصلي.
- التطبيق لا يدخل إلى حساب Facebook ولا يتجاوز صلاحياته.
